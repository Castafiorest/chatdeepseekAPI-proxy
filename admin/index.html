🔐 Tambah Akun via Login Chrome

Login DeepSeek lewat browser tanpa npm run auth. Server akan membuka jendela Chrome khusus; kamu login di sana, lalu klik Selesai — simpan akun.

  1. Klik Buka Chrome & Login
  2. Login DeepSeek di jendela Chrome yang muncul
  3. Kirim 1 pesan singkat (mis. ok) di chat DeepSeek
  4. Klik Selesai — simpan akun di sini
